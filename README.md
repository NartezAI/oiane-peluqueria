# Oiane Peluquería y Bienestar

Web estática (HTML, CSS y JavaScript sin dependencias) de Oiane Peluquería y Bienestar, Carrer del Puig 21, Rafelbunyol (Valencia).

Páginas: inicio, servicios, spa capilar, galería, opiniones, nosotros, reservas y contacto.

## Vista previa local

```bash
node .claude/servidor.js
```

Abre http://localhost:8748.

## Reservas

Los botones de reserva apuntan a la ficha de Fresha. Cuando el salón active la reserva online, cambia `FRESHA_URL` en `assets/js/main.js`.
